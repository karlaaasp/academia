# CT Álvares Cabral

Projeto de criação de um site para o **CT Álvares Cabral**, uma academia de bairro. A proposta é apresentar o espaço e facilitar o acesso às principais informações para quem deseja começar a treinar com praticidade.

> **O projeto está em desenvolvimento contínuo.** Novas melhorias foram aplicadas para deixar a identidade visual mais moderna, melhorar a legibilidade e ampliar a experiência em dispositivos móveis.

## Sobre o projeto

O site reúne páginas para apresentar a academia, seus planos e horários de funcionamento, além de oferecer uma forma de contato. A navegação foi organizada para ser mais clara e a interface visual foi atualizada com uma identidade mais premium e funcional.

## Páginas

- `index.html` — página inicial com apresentação, destaques e CTA para agendar aula experimental.
- `planos.html` — opções de planos e informações sobre o que cada um inclui.
- `horarios.html` — horários de funcionamento e aulas coletivas.
- `contato.html` — formulário para demonstrar interesse em uma aula experimental ou enviar uma dúvida.

## Melhorias recentes

- Layout mais moderno e consistente em todas as páginas.
- Ajustes de acessibilidade para navegação por teclado e contraste.
- Estilo responsivo para telas menores.
- Reestruturação visual dos planos, tabela de horários e formulário de contato.
- Correção de problemas de CSS para manter o comportamento esperado em mobile.

## Tecnologias

- HTML5 para a estrutura das páginas.
- CSS3 para a apresentação visual e os estilos compartilhados.

## Estrutura do repositório

- `style.css` — estilos utilizados nas páginas.
- `imagens/` — imagens usadas no site.
- Arquivos `.html` — páginas e conteúdo do projeto.

## Como visualizar

Não é necessário instalar dependências. Clone o repositório e abra `index.html` em um navegador:

```bash
git clone https://github.com/karlaaasp/academia.git
cd academia
```

Depois, abra o arquivo `index.html` no navegador.
